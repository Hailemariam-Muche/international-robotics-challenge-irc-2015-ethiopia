# Hardware Development

This section documents the robotic hardware development and integration activities associated with the International Robotics Challenge (IRC) 2015.

## Hardware Development Activities

- Robot mechanical assembly
- Electronic circuit assembly
- Microcontroller integration
- Sensor interfacing
- Motor and actuator interfacing
- Power-system integration
- Wiring and connection
- Hardware–software integration
- System troubleshooting

# International Robotics Challenge (IRC) 2015 – Ethiopia

## Embedded Systems & Code Deployment Team Advisor

### Project Overview

The International Robotics Challenge (IRC) 2015 project involved the
development, integration, testing, and preparation of a robotic system
for participation in an international robotics competition.

I served as an **Embedded Systems & Code Deployment Team Advisor**,
providing technical guidance in embedded-system development,
hardware–software integration, programming, code deployment, testing,
debugging, and competition preparation.

## Role and Responsibilities

- Advised the team on embedded-system implementation.
- Supported microcontroller programming and firmware development.
- Guided sensor and actuator integration.
- Supported electronic circuit assembly and hardware integration.
- Assisted with embedded C/C++ programming and debugging.
- Supported firmware/code deployment to the robotic platform.
- Guided hardware–software integration and functional testing.
- Assisted with troubleshooting and system verification.
- Supported the team during competition preparation.
